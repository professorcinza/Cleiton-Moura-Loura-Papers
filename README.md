## English

Public writings of Cleiton Moura Loura. Kept separate from the code, the prototypes and the [ponte-brasil-china](https://github.com/professorcinza/ponte-brasil-china) hub. Each text is born in all four languages in the same commit, or it is not born.

> I begin this work dedicated to all those on the periphery of every nation who, even in hardship, make the impossible possible.

This repository holds the UMC paper as four separate files, one per language — **[paper-umc.en.md](paper-umc.en.md)** (English) · [paper-umc.pt.md](paper-umc.pt.md) (Português) · [paper-umc.es.md](paper-umc.es.md) (Español) · [paper-umc.zh.md](paper-umc.zh.md) (中文). Each language is origin, not translation (UMC-002).

**The paper.** The Universal Computational Model (UMC) replaces *Large Language Model* (LLM) as the guiding concept: *large* names scale, *universal* names an obligation of reach (every language as origin, every margin as a first-class user, every inference with a visible energy account), *computational* names the door (only the symbol that admits a computational model enters). The single paper consolidates the whole line of work:

| Part | Content |
|---|---|
| I | The concept — telos, axiom (symbolic representation ⊆ language), sieve, limits |
| II | Prior-art map — what already exists, the gap, novelty fraud (UMC-001–011) |
| III | Formal foundations — $L_U$, the linguistic universality hypothesis, the $R^*$ problem |
| IV | Spec UMC-001–011 — requirements and verification paths |
| V | Implementation agenda — phases 0–4, in order |

**Status.** Spec UMC-001–011: `draft`. No artefact exists. No line of weights without a spec that governs it (UMC-007). Spec before weights. The next step of the 27/08/2026 continuation is not a training run.

**How to cite:** Loura, C. M. (2026). *The Universal Computational Model (UMC)*. Cleiton-Moura-Loura-Papers. https://github.com/professorcinza/Cleiton-Moura-Loura-Papers

## 中文

Cleiton Moura Loura 的公开著述。与代码、原型及 [ponte-brasil-china](https://github.com/professorcinza/ponte-brasil-china) 枢纽分开存放。每一文本都在同一 commit 中以四种语言同时诞生，否则不诞生。

> 我将此工作献给世界各国边缘上的人们——他们纵有艰难，仍使不可能成为可能。

本仓库将 UMC 论文分为四个独立文件，一种语言一个 — **[paper-umc.zh.md](paper-umc.zh.md)**（中文）· [paper-umc.en.md](paper-umc.en.md)（English）· [paper-umc.pt.md](paper-umc.pt.md)（Português）· [paper-umc.es.md](paper-umc.es.md)（Español）。每一种语言都是源头，不是翻译（UMC-002）。

**论文。** 通用计算模型（UMC）取代 *Large Language Model*（LLM）为指导性概念：*large* 命名规模，*universal* 命名抵达的义务（每一种语言皆为源头，每一处边缘皆为一等用户，每一次推理皆有可见的能耗账），*computational* 命名门（只有承认计算模型的符号才能进入）。单一论文整合了整条工作线：

| 部分 | 内容 |
|---|---|
| I | 概念——telos、公理（符号表征 ⊆ 语言）、筛、界限 |
| II | 先有工作地图——已存在者、空白、新颖性欺诈（UMC-001–011） |
| III | 形式基础——$L_U$、语言普遍性假说、$R^*$ 问题 |
| IV | Spec UMC-001–011——需求与核验之路 |
| V | 实施议程——阶段 0–4，依序 |

**状态。** Spec UMC-001–011：`草稿`。无制品。没有管辖它的 spec，就没有一行权重（UMC-007）。先 spec 后权重。27/08/2026 延续的下一步不是一次训练。
