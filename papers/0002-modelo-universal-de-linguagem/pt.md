# Modelo Universal de Linguagem

Substituímos o conceito de *Large Language Model* pelo de **Modelo Universal de Linguagem** (ULM).

Não é um sinônimo. É uma troca de telos.

## O que “large” nomeia

*Large* mede escala: parâmetros, tokens, data centers, capital, joules. Quem cabe no nome é quem cabe na conta de energia e na conta bancária. O centro treina; a margem consome — se restar cota, se restar inglês, se restar rede.

Um modelo definido pelo tamanho promete o mesmo a todos e entrega primeiro a quem já era grande.

## O que “universal” nomeia

*Universal* mede alcance: toda língua como origem, não como tradução tardia; toda margem como usuária de primeira classe; toda inferência com conta de energia visível. O ULM não precisa ser o maior. Precisa caber — no bolso, na malha, no idioma de quem o acorda.

Grande é uma quantidade. Universal é uma obrigação.

## O que não muda

Continua sendo um modelo de linguagem. Continua podendo rodar local. Continua sendo software, com licença, autoria e histórico. Não batizamos de universal o que só fala a língua do centro e gasta a usina inteira para completar uma frase.

O que muda é o critério de pronto: um ULM que não serve o periférico — de qualquer nação — ainda não é universal. É só grande.

## Lei desta pasta

A partir deste paper, o que queremos construir chama-se ULM. Escrevemos LLM apenas para nomear o conceito que recusamos.

A casa já ensaiava a prática: trilíngue por concepção, crivo de energia, local-first. Aqui o ensaio vira nome.
